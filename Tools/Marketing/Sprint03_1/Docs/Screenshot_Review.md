# Store screenshot review (Sprint 03.1)

**Reviewed:** the eight English App Store screenshots from Sprint 03 (`FinalSprint03/06_StoreAssets/AppStore/Screenshots_*/en/`, 1320×2868 and the other sizes) against the brief's checklist. The other languages have the same layouts.

| Check | Finding |
|---|---|
| Board readability | Boards fill about 80% of the width, and tiles, Plops and mechanics are clearly readable. |
| Contrast | Plum headlines on pastel gradients read well at store thumbnail size. |
| Text margins | Headlines sit inside the top safe area with even side margins. |
| Composition variety | Single board (01–04, 07, 08), stacked multi-world collage (05), Character Studio UI (06). |
| Typography | Nunito ExtraBold throughout, two lines, consistent size. |
| Feature accuracy | Every screen is a real capture: L102, L57, L19, L155, L4/L144/L46, Studio, Daily, L67 Perfect. |
| Visible characters | Real Plops appear on every board, and 06 shows the hero up close. |

**Decision:** no re-export. None of the changes we considered would be a meaningful improvement, and the brief asks not to rebuild them without one.

Optional polish for the owner to decide:
- On **08 "SWEET DREAMS!"** the corner mascot sticker is awake. A sleeping sticker with closed eyes would match the trailer's ending better.
- **06 and 07** were captured on the Android emulator. The UI is identical, but they could be re-captured on iOS.
