Development preview preferences loaded representative campaign levels and
replayed the moves for the completion and recovery screenshots. A separate
emulator save fixture made the World picker show both available and locked
chapters. All input and board rendering used the shipped gameplay scene.

The [12-second gameplay clip](gameplay.mp4) shows the Android player
using touch input to trigger Level 8 recovery and return to the puzzle.
The recording is 720×1280 and has no audio track.

The Phase 5 Android comparison captures show [Level 8](baseline-phase5-level8.png)
and [Level 29 completion](baseline-phase5-completion.png).
