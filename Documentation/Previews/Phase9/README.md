# PLOP! Phase 9 previews

All images come from the running implementation:

- **Android screenshots:** the Phase 9 ARM64 development APK on the Android API 37 emulator (1080×2400). No physical phone was connected.
- **`sheets/` renders:** the shipped `PlopView` rig and atlas, rendered by the Editor capture tool (PLOP → Characters → Capture Reference Sheets).

None of this is concept art.

The Studio screenshots before `gameplay-sleeping-complete.png` were taken with the build that still placed side accessories at the upper right. That screenshot exposed the bow hidden by the Nest's match symbol. The World screenshots use the fixed build, with accessories at the upper left.
